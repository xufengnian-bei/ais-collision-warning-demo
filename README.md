# AIS 船舶碰撞预警 Demo

本项目提供一屏式双船会遇仿真：选择不同角度、曲线航迹的案例，或在画布上摆放两艘船，设置位置、航速、方向和航点，点击“开始仿真”观察运动轨迹和碰撞预警。主船临近危险时停车，安全后从停车位置沿原航迹继续。预警评分按需求文档实现，停车控制作为单独的仿真运动功能。

下载或克隆本仓库后，按照下方“启动”运行即可体验。可在“载入场景”中打开 [曲线交叉示例](examples/curved-crossing.json) 或 [同线受阻示例](examples/blocked-head-on.json)，分别观察本船停车后续航、双方停车等待的过程。

仿真器根据用户设置生成轨迹，经 pyais 编成标准 AIS NMEA 报文，通过实际本机 UDP 套接字发送与接收，再进行状态对齐、DCPA/TCPA 计算、风险融合和实时展示。报文查看、数据导入和详细报告位于“态势”页面。

当前使用合成轨迹，提供 CSV / 带完整时间戳的 NMEA 文件导入。软件收发仿真不包含射频发射、调制解调或 SDR 硬件。用户设置的航点定义原始参考航迹，停车只改变仿真运动进度，不修改预警公式。

## 启动

需要 Python 3.12 或更高版本、Node.js 20.19+ 或 22.12+（建议 Node.js 22/24）。首次安装依赖需要网络，安装完成后默认离线态势界面不依赖外部地图服务。

Linux / macOS，在项目目录运行：

```bash
./start.sh
```

Windows PowerShell，在项目目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

打开 **http://127.0.0.1:8765/**。默认 UDP 接收端口为 `127.0.0.1:10110`，接口文档为 `http://127.0.0.1:8765/docs`。服务启动后场景处于暂停状态，已完成第 0 秒的报文收发。

若端口被占用，可指定环境变量：

```bash
AIS_HTTP_PORT=8766 AIS_UDP_PORT=10111 ./start.sh
```

```powershell
$env:AIS_HTTP_PORT = '8766'
$env:AIS_UDP_PORT = '10111'
.\start.ps1
```

Linux 和 Windows 的虚拟环境不可直接互用。将代码复制到另一系统后，删除旧 `.venv`，让启动脚本重新创建。服务默认仅监听本机，不向公网发布。

若前端已经构建，可直接运行后端，无需再次安装或构建：

```bash
.venv/bin/python -m uvicorn backend.app:app --host 127.0.0.1 --port 8765
```

## 演示流程

1. 打开页面默认进入“会遇场景实验室”。左侧案例库包含 30°、45°、60°、90°、120°、150°、180° 会遇，以及左侧交叉、追越、平行同速和安全交叉，共 14 个可编辑案例（新增曲线交叉、S 形会遇和曲线安全通过）。
2. 点击案例卡片查看双船摆放。拖动船体调整初始位置，拖动船前方的圆形手柄旋转航向；也可以选中本船或目标船，在右侧精确输入 X / Y、航速和航向。
3. 点击“开始仿真”，两船按设置运动，画布显示已走轨迹，下方显示距离、DCPA、TCPA、综合风险和风险曲线。
4. 支持暂停、继续、单步、1–20× 倍速、时间轴回放、推演至首次预警和完整推演。
5. 点击“返回编辑”保留原始摆放与参数，调整后重新仿真。仿真中参数锁定，避免中途修改起始条件。
6. 点击“保存场景”，场景保存到本机 SQLite，并出现在“我的场景”；重启服务后仍可打开。可以导出 / 载入场景 JSON，在其他电脑复用。
7. 点击“态势详情”可查看地图、目标列表、预警事件和 AIS 原始报文。报告与结果导出继续可用。

坐标采用局部米制平面：东向 X 为正、北向 Y 为正。初始位置范围为各轴 ±10000 米，航速 0–60 节，航向为真北 0°、顺时针增加；90° 为东、180° 为南、270° 为西。仿真时长 30–3600 秒，界面提供常用时长选项。草稿还会自动保存在当前浏览器本地；明确点击“保存场景”后才写入“我的场景”。

案例卡片上的角度指双船航向夹角，是否预警仍取决于位置、速度和文档规则。可调整任何案例进行安全通过与危险接近的对比。所有典型案例都是可编辑的起点。

键盘操作：选中船体后方向键每次移动 10 米，Shift + 方向键移动 100 米；选中航向手柄后左右方向键每次旋转 5°。

“态势”页面另外保留原有 8 个确定性场景：多船综合会遇、对遇、交叉、追越、同向同速、会遇后驶离、近距离保护、安全交叉，可用于算法与异常报文验证。船名、MMSI 和轨迹均为演示配置，不代表真实船舶事故。


## 一屏布局和航点曲线

页面随窗口高度调整，主页面保持在一屏。案例库和航点列表分页，右侧按“运动参数 / 航点轨迹 / 停车保护”切换；窄屏通过顶部按钮打开案例库或参数面板。极矮窗口的参数区域采用局部滚动，主页面不滚动。

选择本船或目标船，在“航点轨迹”中选择平滑曲线，点击画布依次添加航点。编号点可以拖动，也可在列表中修改 X / Y、上移、下移或删除。每艘船独立设置，支持一艘走直线、另一艘走曲线。

平滑轨迹使用[向心 Catmull–Rom 插值](https://www.cemyuksel.com/research/catmullrom_param/)（alpha=0.5），穿过起点和航点，以弧长查表推进船位。速度按设定航速，COG 随曲线切线更新；到达最后航点后停船。支持切换为航点折线。每艘船最多 32 个航点，相邻点至少相距 1 米。

画布虚线为原始航迹，实线为实际航迹。场景 JSON 保留 waypoints 与 interpolation，重新载入后可继续编辑。

## 主船自动停车与续航

“停车保护”默认启用，默认停车距离 350 米、恢复距离 600 米、向前检查 30 秒、连续安全确认 5 秒，均可配置。

每秒检查双船沿实际航迹继续运动是否即将进入保护范围；另外向前检查至少 180 秒的目标航迹，提前判断本船下一步的位置是否会挡住目标船的通道，尽量在通道外停车。主船停车冻结本船航程，AIS 航速输出 0。目标能在保护距离外通过时继续航行。距离恢复到安全阈值、向前检查无冲突并持续满足确认时间后，主船从停车点继续剩余航段。恢复距离大于停车距离，避免在同一阈值附近抖动。

停车不是暂停仿真：全局时间、AIS 报文和风险评估继续运行。报告 motion_control.events 记录 stop / resume 与 target_stop / target_resume 时刻、原因和对应本船航程；逐秒 CSV 包含 own_sog、target_sog、own_held、target_held。双方停车时，两船 AIS 航速均输出 0。

本船和目标船均遵守同一个停车保护距离，默认 350 米。运动提交前检查整段相对运动轨迹，包括曲线和高速跨步；目标不能通过保护范围穿越停住的本船。两船完全同线正面对驶、曲线航路被占用等无法安全通行的情况，双方保持停车，界面显示“双方停车 · 航路受阻”；可返回编辑修改航点，留出通道。默认 150°、180° 和 S 形案例可用于观察航路受阻，曲线交叉和 90° 交叉展示通过后续航。已有近距离初始场景不会被瞬移到 350 米外：以初始间距为保护下限，允许驶离，禁止进一步接近。

所有软件仿真场景默认启用主船停车保护；旧 JSON 缺少设置时自动补全默认值。需要对照原文的匀速风险结果时，可关闭场景中的停车保护，或在终端脚本增加 --no-auto-stop。历史轨迹文件回放按已记录的运动状态分析。

## 流畅播放

会遇画布使用 requestAnimationFrame，按显示器刷新节奏绘制，普通 60 Hz 屏幕以约 60 FPS 为目标。船位、航向线、保护圈和标签同步更新；静态航迹和风险图表不跟随每个动画帧重算。船体符号随缩放和保护距离调整，避免符号放大造成“船体穿过”的视觉错觉；符号不是船舶真实尺寸。

服务端最多每 100 毫秒推送一次有变化的完整状态（原为 400 毫秒），空闲时每 5 秒发送一次心跳。AIS 收发、风险计算和 CSV 保持每仿真秒一次。服务端在已执行并收到 UDP 报文的运动区间内生成 0.25 秒关键帧，前端使用统一时间轴插值，包括曲线路径和航向跨 0° 的旋转；不预测尚未执行的未来船位。正常动画约落后一个状态更新间隔，网络停更后停在最后一个有效位置。

新停车事件、暂停、单步、时间轴跳转、切换场景和倍速变更会同步到确认船位，取消旧动画，避免停车后滑行或回放倒退时插值穿越。暂停后停止逐帧循环。测试覆盖关键帧曲线插值、共同时间轴、停车冻结、跳转、断流不外推和 SVG 中间帧绘制；实际 FPS 取决于浏览器、屏幕刷新率和设备性能。

更新代码后需重启后端并刷新浏览器。只刷新页面可以加载新前端，停车保护的 Python 逻辑需要重启服务才生效。

## 界面和数据

- 默认离线地理坐标视图采用 WGS 84，显示船位、航向、历史轨迹、CPA 预测、监测圈和距离保护圈。网格为视觉辅助，以比例尺和距离圈为准。
- 图层按钮可切换 OpenStreetMap 在线底图。在线地图不可用时可切回离线视图；核心功能不受影响。
- 数据存于 `data/ais-demo.db`，包含运行、解析后的动态位置、收发报文、逐时刻风险、历史报告和保存的自定义场景。每次重置、切换场景、本船或参数都会创建新运行。
- 时间轴向后跳转时，逐秒重新计算并记录新运行。向前快进也实际执行中间各秒，不跳过首次预警统计。
- 网页历史曲线显示最近 600 个有效评价时刻，地图轨迹为采样显示；CSV 和 SQLite 保存本次运行的完整评估记录。
- `GET /api/runs` 返回最近 50 次运行，`GET /api/runs/{run_id}/report` 读取历史报告。

## 文档算法

内部距离单位为米，时间为秒，AIS SOG 输入和展示使用节，计算时换算为米/秒。COG 使用真北为 0°、顺时针。

在本船局部东 / 北坐标中，以 WGS 84 测地线距离、方位建立短距离相对位置，并使用双船当前速度向量计算：

```text
r = target_position - own_position
v = target_velocity - own_velocity
TCPA = -(r · v) / ||v||²
DCPA = ||r + TCPA × v||
```

对于指标 `x`，设 `q=(x-a)/(b-a)`，使用文档 Z 型函数：

```text
x <= a             : μ(x) = 1
a < x < (a+b)/2    : μ(x) = 1 - 2q²
(a+b)/2 <= x < b   : μ(x) = 2(1-q)²
x >= b             : μ(x) = 0
```

默认参数：

| 参数 | 默认值 |
| --- | --- |
| DCPA 风险高 / 低边界 | 300 / 1000 m |
| TCPA 风险高 / 低边界 | 60 / 240 s |
| 当前距离风险高 / 低边界 | 300 / 1000 m |
| 综合风险 | 三项等权平均 |
| 风险预警阈值 | 0.72 |
| 紧急距离保护 | 350 m |
| 监测半径 | 2 海里，可配置 |
| 评价间隔 | 1 s |
| 状态有效期 / 最大离线插值间隔 | 30 s，可配置 |

`TCPA < 0` 时只将时间风险设为零，距离保护继续有效。相对速度近零时，TCPA 输出 `null`，DCPA 取当前距离，时间风险取零，避免除零或虚假的高紧迫风险。

**监测半径与报警距离是两个参数。** 默认情况下，当前距离达到 1000 米后，综合风险最多为 `2/3`，不能达到 `0.72`。因此，2 海里表示纳入监测的范围，不表示在 2 海里处保证报警。原文规则保留不变，没有额外添加远距离报警规则。

图例中的 CPA 虚线是保持当前速度、航向的运动预测，非避碰计划。综合风险为规则得分，非碰撞概率。

## 实时对齐与文件回放

实时仿真每秒发送动态报文，静态资料按周期发送。开启异步上报时各船采用不同的 2–5 秒间隔。接收端只使用已到达报文，根据上次位置和当前速度进行有界外推，超过状态有效期后停止评估，并显示“数据过期”。乱序的旧动态状态不会覆盖最新状态；相同 MMSI、相同事件时间按重复状态处理。

离线导入先按 MMSI / 时间排序、去重，缺失运动字段使用相邻位置补算，再以 1 秒间隔重构。速度以东 / 北分量插值，避免 `359° → 1°` 插成 `180°`。超过配置间隔的缺口不插值，也不会继续通过实时外推补过该缺口。

离线重构后的状态仍经过 AIS 编码、UDP 和解析，因此保留 AIS 经纬度和速度的编码量化；任意高精度 CSV 经过该链路后可能有小幅量化差异。导出的接收位置重新导入后，默认场景测试可复现预警时刻和峰值风险。

本船可在“规则”对话框选择。Class A 动态位置报文使用 Type 1、静态资料使用 Type 5；Class B 使用 Type 18 和 Type 24。船型和航行状态缺失不单独决定预警。

## 导入格式

CSV 示例：

```csv
mmsi,timestamp,latitude,longitude,sog,cog,ship_type,nav_status,name
413000001,2026-11-05T02:00:00Z,31.1000,122.1832,12,90,70,0,OWN DEMO
413000101,2026-11-05T02:00:00Z,31.0919,122.1988,7,0,30,,TARGET DEMO
```

实际文件须包含至少两艘船的有效轨迹和至少两个不同时间点。`ship_type`、`nav_status`、`name` 为可选字段；`sog` / `cog` 可留空，但需要相邻位置支持补算。支持字段别名 `lat` / `lon` / `speed` / `course`，字段名大小写不敏感。相同 MMSI 和时间的重复行采用最后一行。

`timestamp` 支持 ISO 8601、Unix 秒、Unix 毫秒，无时区时间按 UTC 解释。网页统一显示北京时间。推荐显式使用 `Z` 或 `+08:00`。

导入上限为 8 MB、100000 条动态位置、两小时。无效行和补算情况显示在导入报告。可从界面下载完整合成样例，或使用 `GET /api/sample.csv`。

NMEA 文件支持 `.nmea` / `.txt` / `.log`，每行是一条标准 AIS 语句，前置完整时间戳 NMEA tag block：

```text
\s:AIS-DEMO,c:1793844000.000*HH\!AIVDM,...*HH
```

上述 `HH` 为示意，实际校验和由程序计算。Tag block 和 AIS 语句各自校验。动态报文本身的 UTC 秒字段不是完整日期时间，纯 NMEA 语句缺少完整时间戳时不用于历史回放。仿真和回放将事件时间写入 `c:`，不会把 20× 运行时的主机接收时间错误地当成轨迹时间。

## 导出结果

界面支持单独下载 CSV、JSON、PNG，或 ZIP 结果包。ZIP 包含：

| 文件 | 内容 |
| --- | --- |
| `evaluation.csv` | 每个有效评价时刻的双船状态、距离、DCPA、TCPA、三个风险、综合风险、触发条件及原因 |
| `report.json` | 数据来源、配置、故障开关、首次预警、峰值风险、观测最小距离、事件及收发计数 |
| `scene.json` | 自定义仿真的初始摆放、速度、方向与时长，可在实验室重新载入；仅自定义仿真结果包包含此文件 |
| `tracks.png` | 全时窗有效轨迹、首次预警位置及风险曲线 |
| `transmitted.nmea` | 本次实际发送的带时间戳原始报文，可重新导入 |
| `positions.csv` | 实际解码后的动态位置，可重新导入 |
| `说明.txt` | 文件和单位说明 |

CSV 保留文档规定字段：`timestamp`、`own_mmsi`、`target_mmsi`、`actual_distance_m`、`dcpa_m`、`tcpa_s`、`risk_dcpa`、`risk_tcpa`、`risk_distance`、`collision_risk`、`warning_by_risk`、`warning_by_distance`、`predicted_warning`、`warning_reason`。附加监测范围、数据质量、报文年龄和双船经纬度。

尚未推演结束的报告标记为 `complete=false`。观测最近距离只针对当前已收到的有效数据；首次预警到观测最近点的时间差不能提前解释为完整时窗的预警提前量。过期状态终止当前告警事件时，结束原因明确记录为“数据过期，停止评估”，不表示船舶风险已解除。

## 开发与验证

```bash
# 后端
.venv/bin/python -m uvicorn backend.app:app --host 127.0.0.1 --port 8765
# 另开终端运行前端，访问 http://127.0.0.1:5173
npm run dev
```

只运行算法、实际 UDP 收发和结果导出，可在终端执行：

```bash
.venv/bin/python scripts/run_scenario.py --scenario mixed --output-dir artifacts/example
```

Windows 对应使用 `.venv\Scripts\python.exe scripts\run_scenario.py --scenario mixed`。脚本自动选择空闲 UDP 端口，不占用网页服务的接收端口，并打印每艘目标的首次预警、峰值风险、观测最近距离及提前量。

前端开发代理默认后端 8765；修改后端端口时同步修改 `vite.config.ts`。部署式本地启动由 FastAPI 直接提供 `dist`，无需第二个前端进程。不要使用多个 Uvicorn worker；Demo 只有一个共享仿真与 UDP 接收实例。

```bash
.venv/bin/python -m pytest -q
npm test
```

## 项目结构与开源组件

```text
backend/algorithm.py   风险公式、几何和状态对齐
backend/ais.py         AIS 编解码、NMEA 校验、分片、UDP 接收
backend/scenarios.py   八个合成场景
backend/scene_editor.py 双船场景、角度/曲线案例与起始状态预览
backend/routes.py      曲线拟合、弧长和运动方向
backend/motion_control.py 主船停车、等待与原航迹续航
backend/importer.py    文件导入和离线重构
backend/engine.py      时钟、收发、风险、事件、SQLite
backend/exporter.py    CSV、JSON、PNG、ZIP
backend/app.py         FastAPI / WebSocket / 本地静态页面
frontend/src/          React、Leaflet 和风险图界面
frontend/src/ScenarioLab.tsx 场景案例库、参数编辑和仿真控制
frontend/src/EncounterCanvas.tsx 船位拖拽、航向手柄和运动画布
frontend/src/playback.ts 已执行关键帧插值、暂停与停车冻结
tests/                算法、传输、导入和端到端测试
```
